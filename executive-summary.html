Submission guide · evidence-first decision

DO NOT SUBMIT: no file is cleared

There is no approved TIFF download in this repository. Historical TIFFs and the previously advertised karage3-unique-offcat artifact are research artifacts, not authorized submissions. Do not upload them.

Do not treat a target score or local format check as a score prediction or organizer approval. New scores require a properly controlled spatial holdout; leaderboard results require a submission-page receipt linked to the exact raster hash.

When a candidate is eventually cleared, submission steps

  1. Use only a candidate explicitly marked OK TO SUBMIT by the current release decision and separate selector. If there is no such candidate, stop.
  2. Download the named single-band GeoTIFF (or its single-TIFF ZIP) from the approved artifact link. Verify its SHA-256 against the release record.
  3. Run the repository's submission validator against the authenticated competition sample/template. Confirm the required CRS, dimensions, geotransform, pixel range [0, 1], and footprint-specific NoData policy.
  4. On DrivenData, choose the GeoTIFF or ZIP in “File to submit”; enter the exact submission name and short method note given by the approved run card; then submit only if the live weekly-cap selector authorizes a slot.
  5. Save the submission-page receipt and returned score, and bind both to the exact uploaded file hash. Label it ORGANIZER-CONFIRMED only when that receipt is preserved.
