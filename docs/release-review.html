How a future valid submission will be released

  1. Use one assigned lane, the canonical cache, evaluator and writer. Test features alone for leakage and freeze buffered whole-segment visible-only folds.
  2. Beat the frozen same-evaluator best on paired spatial HOLDOUT-DTI with a 95% CI. Report evaluator version and withheld positives. Never convert this into a leaderboard estimate.
  3. Check both surface and final support rank correlation and literal directional overlap against every registry raster, with no calibration/density exceptions.
  4. Validate exact saved bytes: single band, finite footprint, [0,1], CRS/shape/transform; diagnose outside-footprint encoding separately. Publish SHA256, unique name and note of at most 140 characters.
  5. A separate selector checks the live weekly cap and eligibility. Only after authorization should the single TIFF or ZIP containing one TIFF be uploaded to the organizer's form.

No human visual inspection is substituted for these automated checks. Missing evidence is a failed gate, not permission to upload.
