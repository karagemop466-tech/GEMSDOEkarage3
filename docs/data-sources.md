## Significant irregularities

* The owner-mirrored `sample_submission.tif` contains the same 60,988 positive cells as the mirrored labels. The official page describes its example as predicting total fault absence. We verified the equality in the mirrored bytes; we cannot establish which file the organizer supplied or why the difference exists. Use the mirror for geometry audits only, not ground-truth authentication.
* The all-finite and null-outside conventions may lead to different results with an irregular footprint. The reported portal error does not establish which convention failed; request an organizer clarification rather than promising acceptance.
* The prompt reports two different leaderboard highs. The official board is authoritative when viewed, but it does not bind a particular historical file hash to a score. No valid score projection or submission-page receipt is present.
* The active shared GEMSDOE32 files are byte-identical to commit `97597a…`. At that pin the binary CLI explicitly rejects continuous inputs. Other shared defects remain open: [buffer #60](https://github.com/buffedlizard55-lab/GEMSDOE32/issues/60), [FP pooling #41](https://github.com/buffedlizard55-lab/GEMSDOE32/issues/41), [leakage #61](https://github.com/buffedlizard55-lab/GEMSDOE32/issues/61), [surface overlap #42](https://github.com/buffedlizard55-lab/GEMSDOE32/issues/42), and [masked pixels #66](https://github.com/buffedlizard55-lab/GEMSDOE32/issues/66). Shared fixes require upstream access; local diagnostics do not replace the shared evaluator.
* A registered calibration lattice is not a geological detector, but the literal any-registry rule does not exempt it. [Our pinned audit](data/historical-audit.json) proves a champion-sized budget must fail the 70% rule; it does not prove that all smaller budgets or all possible continuous fields fail.
