How to submit on DrivenData — step by step

There is currently NO file in this repository that is OK to submit. These steps are for a future file whose run card says verdict: promote and which an independent selector has approved, since weekly slots are limited.
  1. Sign in at drivendata.org — DOE GEMS competition with the account registered for the competition.
  2. Open the Submissions tab of the competition.
  3. Check the file before uploading. It must be a single-band GeoTIFF in EPSG:32611, 3730×3292 pixels, transform (100, 0, 243350, 0, −100, 4508550), float32, with valid values in [0, 1]. Check whole-array finiteness and the official outside-footprint convention separately. The cause of the reported portal range error has not been established. Run locally: .venv/bin/python scripts/check_submission.py FILE.tif --strict-finite; it must print [PASSED].
  4. Upload either the .tif or the .zip that contains only that single .tif. Both forms are produced by scripts/submission_writer.py.
  5. Optional: paste the run card's note (at most 140 characters) into the submission note field, so the score can later be tied to the file hash.
  6. Submit. Save a screenshot or copy of the submission row (time, score, file name) to registry/owner_score_ledger.csv with the file's SHA-256. Without that, a score stays OWNER-REPORTED, not organizer-confirmed.
  7. Remember the official rules: the private leaderboard decides the prizes, and the Final Round re-scores the one selected submission on expanded labels (problem description).
