How a submission is released

No file from this run is OK TO SUBMIT. There is no new TIFF download because the scientific and uniqueness evidence is missing. This is an automatic negative decision, not a request for a human inspector.

  1. Read the run card. Require versioned HOLDOUT-DTI, withheld-positive count, spatial 95% CI, feature canaries, and paired improvement over the current same-evaluator best.
  2. Require complete registry checks on the continuous surface and final dots; reject drift into another method lane.
  3. Use the canonical template submission writer. Reopen the actual saved file and verify one band, finite footprint values, range [0,1], and exact CRS, shape, and geotransform against the official template. Prefer all-finite output to avoid sentinel or NaN range failures. Never silently clip a scientific model to conceal a bug.
  4. Only after validation, publish a one-click TIFF download, SHA256, unique method-based name, and note no longer than 140 characters. Matching bytes is not the only duplicate test.
  5. The separate selector checks eligibility, current competition rules, and the weekly cap on the submission page. No slot is consumed during local validation. This run has no selector authorization.
  6. Once authorized, choose the single-band TIFF on the competition submission form and paste its note. Save the organizer receipt linked to the file SHA256. Only that receipt establishes ORGANIZER-CONFIRMED performance.
