Step 2 — Upload to DrivenData

  1. Open DrivenData GEMS (#306). Go to DrivenData DOE GEMS Competition, sign in, and navigate to the Submissions page.
  2. Upload the file. Select gemsdoe32-novel-faulthalo-conddil-scarp-tc-20261029T183102Z-282c6b01-zeros.tif (or the single-TIFF .zip). The file is pre-clamped to [0, 1] with zero NaN inside the footprint — preventing the range-error portal rejection.
  3. Enter the submission note (≤140 characters). Copy-paste ready:
    Unique fault-halo geothermal targeting: cond x dilation x basement x scarp x TC hotspots 0-1px off catalogue traces, 37654 dots
  4. Save the organizer receipt. Record the DrivenData submission-page confirmation binding filename, SHA-256, timestamp and returned score. Only receipt-backed scores may be labeled ORGANIZER-CONFIRMED.

About the “Predicted values must be in range [0, 1]” error

This error occurs when a submission contains NaN, Inf, or out-of-range float values. This file eliminates it by clamping all footprint values to [0, 1], setting all non-footprint cells to exactly 0.0 with nodata=None, and guaranteeing zero NaN/Inf/sentinels anywhere in the 12,279,160-cell grid.
