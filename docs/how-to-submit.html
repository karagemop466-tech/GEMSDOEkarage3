About the "Predicted values must be in range [0, 1]" error

This error occurs when a submission contains NaN, Inf, or out-of-range float values. karage3-unique-offcat eliminates it by: (1) clamping all footprint values to [0, 1], (2) setting all non-footprint cells to exactly 0.0 with nodata=None, (3) guaranteeing zero NaN/Inf/sentinels anywhere in the 12,279,160-cell grid.
