1. Format rules (official)

  • Single-band GeoTIFF (.tif), or a .zip containing one GeoTIFF. Source: the DrivenData submission-form text quoted by the owner, and the official problem page page 967.
  • Must match the submission format's CRS, shape and geotransform. The reference grid is EPSG:32611, 3,730 × 3,292, 100 m pixels (epsg.io/32611).
  • Values must be in [0, 1]. The owner reported the error "Predicted values must be in range [0, 1]" on a previous attempt.
  • Official rules and submission limits: NLR 96647 (PDF).

2. Uniqueness gate (project rule)

A candidate must have at most 70% of its dots within 3 px of any registered raster, and rank correlation at most 0.90. Measured on 2026-10-29: every retained in-footprint file exceeds 99% against the pinned calibration lattice (saved-byte audit, feasibility receipt).

3. Steps for a future, cleared file (not available now)

  1. Generate the file with a reproducible script committed to this repository.
  2. Run the format validator and the uniqueness gate on the exact bytes to be uploaded. Both must pass.
  3. Read the current run card. It must say ok_to_submit: true and must be signed off by the selector step.
  4. Only then: DrivenData, New submission, choose the file, add a unique name and a note of 140 characters or fewer, and submit. Keep to the weekly cap shown on the submission page.
