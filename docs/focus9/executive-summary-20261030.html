How to submit (step by step — applies only after a candidate is cleared)

  1. Pick a candidate that has passed the random same-area control and beaten the holdout best (0.0967 locally). A candidate that fails either gate is not submitted.
  2. Write the GeoTIFF: single band, float32, EPSG:32611, 100 m, 3730 × 3292 grid; values exactly 0 or 1 inside the footprint; NaN outside. Run scripts/check_format.py with the sample submission as template.
  3. Run the writer audit src/gems32/submission.py audit_geotiff (nan mode). It must pass all checks, including zero catalogue leakage.
  4. Give the file a unique name (≤ 140-character comment). Confirm its SHA-256 is not in the registry and that the literal uniqueness screen passes (within-3 px ≤ 70 %; |Spearman| ≤ 0.90).
  5. Upload only after steps 1–4 pass. Record the portal's response and keep a receipt. An organizer receipt is needed before any ORGANIZER-CONFIRMED claim.
